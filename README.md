**For Help, Use the Commands Below**

1. `uv run pre-commit install`
   Initializes the pre-commit Git hook for the project. This ensures that
   whenever you create a new commit using `git commit -m "some-message"`,
   the configured pre-commit hooks are automatically executed.

2. `uv run python manage.py runserver`
   Starts the Django development server.

3. `uv run python manage.py --help`
   Lists all available Django management commands configured for the project.
